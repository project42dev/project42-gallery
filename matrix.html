Every theme, against every layout

Themes own colour, typeface and imagery. Layouts own measure, spacing rhythm, density, radii and the type ramp. They are independent, so the two together are what you actually ship — this page renders all — combinations from the real published bundles. Pick one, then paste the snippet it gives you into project42.config.json. That is the whole change.

One theme here is not a Gallery theme. portal-default Ships with the platform — it is the stock theme a fresh install renders with, owned by project42-platform, and it stays there. It is previewed from a vendored, hash-locked copy of the platform release so you can see what you already have next to what you could choose. Everything else on this page is published by this Gallery and downloadable from it.

This is the Gallery’s own specimen surface, in the way a Hugo theme ships an example site: it exercises the complete token vocabulary so nothing a bundle defines is invisible here. It is a faithful preview of the design system, not a pixel copy of every portal page.
