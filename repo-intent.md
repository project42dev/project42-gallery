# Repo intent — project42-gallery

**Project 42 Theme Gallery, permanent themes, and theme authoring specifications.**

## What this repo is

The official community theme gallery, theme repository, and theme authoring kit for
Project 42, live at https://gallery.project-42.dev. Ships six built-in permanent
themes (Cosmic Answer, Learning Portal, Model Constellation, Field Signal, Open
Orbit, Galactic Guide), each with its own accent palette and atmosphere.

## Shape

- `themes/` — the theme definitions
- `generator/` — theme generation tooling
- `docs/THEME_AUTHORING_GUIDE.md`, `docs/THEME_SCHEMA.md` — how to author a new
  theme and the JSON schema it must satisfy

## How it relates to other repos

- Themes here are consumed by sites built on **`project42-platform`**

## Status

Active. Apache-2.0 licensed, open to community theme contributions.
